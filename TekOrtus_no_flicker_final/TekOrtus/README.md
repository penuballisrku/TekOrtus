# TekOrtus website

Static corporate website for TekOrtus, Nellore, Andhra Pradesh. HTML5, CSS3, JavaScript, Bootstrap 5, AOS, Font Awesome. No backend.

## Run
Open `index.html` in a browser, or use VS Code Live Server. Keep the `assets` folder next to the HTML files. An internet connection is needed for the CDN libraries and fonts.

## Deploy
Upload the folder to GitHub Pages, Netlify, or any static host.

## Replace before launch
- Email `pkumar@tekortus.com`
- Sample stats on the home page, sample projects, and job openings
- Illustrations in `assets/images` with real photos or screenshots
- Contact and demo forms are UI only; connect an email service (for example Formspree) to receive messages
