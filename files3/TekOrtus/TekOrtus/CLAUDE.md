# TekOrtus

## Project Overview

TekOrtus is a modern software company website inspired by leading IT service providers such as Infosys, but with a unique contemporary design and branding.

This project is a static corporate website only.

## Project Type

Corporate Software Company Portal

## Location

Nellore, Andhra Pradesh, India

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- AOS animations
- Font Awesome Icons

## Important Constraints

- No Backend
- No Database
- No APIs
- No Authentication
- No Admin Portal
- No CMS

Generate only static frontend code.

## Development Instructions

- Use semantic HTML5.
- Write clean and maintainable CSS.
- Use Bootstrap 5 for responsive layout.
- Generate professional placeholder content where needed.
- Create reusable components such as navbar, hero section, cards, footer, and CTA sections.
- Focus on modern UI/UX.
- Ensure all pages share a consistent design system.
